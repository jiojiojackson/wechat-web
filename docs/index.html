WECHAT WEB / UBUNTU SERVER

把微信放进浏览器。
把访问留给自己。

基于 WeChat Selkies，补充源站身份验证、容器隔离与手机 Safari 适配。通过 Cloudflare Tunnel 连接，无需新增应用公网入站端口。

阅读完整安装说明 ↗查看源码 ↗

在服务器执行

独立的 Ubuntu 22.04 / 24.04 / 26.04 LTS，ARM64 或 x86_64，至少约 4 GiB 内存。需要 sudo 和 Cloudflare 域名。

curl --proto '=https' --tlsv1.2 -fsSL https://jiojiojackson.github.io/wechat-web/install.sh -o wechat-web-install.sh && bash wechat-web-install.sh

向导会说明域名、Tunnel、Access 的配置，验证登录拦截后再部署，完成时提供用户名和随机密码。首次构建需要一些时间。

双重验证

Access 邮箱登录 + 源站验签与邮箱名单 + 本地随机密码。

隔离运行

用户映射、最小权限、私网与云元数据阻断、资源上限。

手机可用

中文输入、自动尺寸、可拖动工具栏、照片与文件上传。

先准备三件事

  1. Cloudflare 托管域名，选择专用子域名。
  2. Tunnel 路由指向本服务器的 http://localhost:13000。
  3. Access 保护完整域名，仅允许明确邮箱，准备团队名称和 AUD。

已有 SSH Tunnel 可以复用。全部凭证在你自己的服务器保存，此页面没有凭证输入框，也不会收集安装配置。
